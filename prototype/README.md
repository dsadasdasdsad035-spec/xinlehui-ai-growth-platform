# 昕乐绘 AI 课后反馈平台｜高保真交互原型

## 启动方式

```powershell
pnpm install
pnpm run dev
```

浏览器打开 `http://127.0.0.1:5173`。登录页可直接点击“老师 / 家长 / 管理员”进入对应体验身份。

## 推荐体验路径

1. 登录页点击“登录”验证空表单错误，再用“老师”快速体验。
2. 老师工作台点击“开始制作课后反馈”。
3. 选择班级 → 模拟上传作品 → 选择 AI 应用 → 查看生成进度 → 编辑点评 → 确认发布。
4. 从右上角身份菜单切换为“家长”，查看最新反馈、成长档案和授权管理。
5. 切换为“管理员”，体验应用中心、模型供应商、模型池、生成日志和权限设置。
6. 在课后反馈/生成任务页面使用“状态预览”切换正常、空状态和错误状态。
7. 点击左下角“原型导览”，查看全部页面和快捷入口。

## 交互说明

- 数据均为前端模拟，不会上传真实儿童素材，也不会调用真实模型供应商。
- AI 生成使用短延时模拟，发布后会在本地状态中新增生成任务。
- 应用启停、卸载、新增，连接测试、授权撤回、权限保存均有弹窗或 Toast 反馈。
- 响应式覆盖桌面、中等宽度和 390px 移动端；移动端使用抽屉导航。
- 每个主要页面标题旁均显示对应 PRD 功能编号。
